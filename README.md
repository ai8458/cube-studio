# 魔方实验室 · Cube Studio

[在线体验](https://ai8458.github.io/cube-studio/)

Three.js 三维魔方，支持随机打乱、外层及 M/E/S 中层拖动、选层高亮与方向提示、逐步与自动还原。

- 撤销与重做：Ctrl / Cmd + Z，Ctrl / Cmd + Shift + Z 或 Ctrl + Y。
- 点击历史步骤查看当时的状态；可播放、暂停或继续回放。从过去开始新转动会替换后续记录。
- 自动保存魔方、历史位置、视角、计时、转动方向与速度；刷新后继续，离线期间不计时。进度仅保存在同一浏览器中，重新开始会清空。

全部计算在浏览器内进行，无需账户或后台服务。使用静态 HTTP 服务器打开本目录即可运行。第三方运行依赖及其 MIT 许可证见 `vendor/`。
